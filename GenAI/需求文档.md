# 需求文档

## 1. 应用概述

### 1.1 应用名称
NFC打卡闹钟

### 1.2 应用描述
一款无需联网、本地运行的安卓独立应用。在工作日设定时间开始发出消息提醒与震动，支持每分钟重复提醒及手动延迟5分钟，直至用户通过扫描绑定的NFC卡完成验证打卡或通过设置进行今日跳过操作，停止当日提醒并在日历中记录历史状态。

只需兼容Android手机，无需兼容其他设备

## 2. 用户与使用场景

### 2.1 目标用户
需要借助物理NFC卡片（如放置在特定位置的卡片）辅助早起、准时打卡或养成打卡习惯的用户。

### 2.2 核心使用场景
- 用户在设置页面录入自己的NFC卡片信息，并设置工作日提醒时间与间隔时间。
- 每个工作日到达设定时间后，App发出通知提醒与震动，用户可选择手动延迟5分钟，或使用NFC卡片贴近手机进行扫描验证。
- 用户若因特殊情况当日无法打卡，可在设置页面通过连续三次确认操作跳过今日打卡。
- 扫描成功打卡或跳过打卡后，停止当日提醒，并在日历页面查看历史记录状态（已打卡/已跳过）及下次打卡时间。

## 3. 页面结构与功能说明

### 3.1 页面结构

- NFC打卡闹钟App
  ├── 日历页面（Tab 1）
  └── 设置页面（Tab 2）

### 3.2 功能说明

#### 3.2.1 日历页面
- 日历展示：展示当月日历视图，分别使用不同样式标记「已打卡」与「已跳过」的历史日期。
- 打卡统计：展示历史累计成功打卡天数。
- 实时与下次打卡信息：在日历下方展示当前日期、当前实时时间、下次计划打卡时间。
- 提醒控制操作：在提醒触发状态下，提供「延迟5分钟」操作按钮；支持贴卡即时感应打卡。

#### 3.2.2 设置页面
- NFC卡片录入：提供录入入口，用户将NFC卡贴近手机完成卡片ID读取并保存到本地；展示当前已绑定卡片状态（已绑定/未绑定）。
- 开始提示时间设置：设置工作日触发提醒的具体时间点（时/分）。
- 提示间隔时间设置：设置提醒未完成时的重复触发间隔时间（默认1分钟）。
- 今日不打卡：提供「今日不打卡」按钮，点击后需进行连续3次确认弹窗，3次确认均完成后生效，用于跳过今日打卡并立即终止今日提醒流程。

## 4. 业务规则与核心逻辑

### 4.1 提醒与打卡规则
1. 触发周期：仅在工作日（周一至周五）到达设定的开始提示时间时触发提醒。
2. 提醒表现：发送系统消息通知并伴随震动。
3. 重复提醒规则：若未进行NFC打卡验证、未手动延迟且未跳过打卡，每隔设定的间隔时间（默认1分钟）重新发送消息并震动。
4. 延迟规则：点击「延迟5分钟」后，暂停当前提醒，并在5分钟后重新恢复提醒流程。
5. 打卡验证规则：用户通过手机NFC感应区扫描卡片，当读取的NFC卡信息与设置中录入的卡信息一致时，判定打卡成功，立即停止当日提醒流程。
6. 今日跳过规则：在设置页面点击「今日不打卡」并完成连续3次确认后，判定今日跳过打卡，立即终止当日后续提醒流程；若中途取消任一次确认，则不生效并保持原状态。
7. 数据记录规则：
   - 打卡成功后，日历对应日期标记为已打卡样式，历史累计打卡天数加1，更新下次打卡时间。
   - 跳过打卡后，日历对应日期标记为已跳过样式（与已打卡样式明确区分），历史累计打卡天数不增加，更新下次打卡时间。

## 5. 异常与边界情况

| 场景 | 规则说明 |
| --- | --- |
| 未录入NFC卡时到达提醒时间 | 提示用户需先完成NFC卡录入方可完成打卡闭环 |
| 扫描未匹配的NFC卡 | 提示卡片不匹配，保持提醒状态不变 |
| 当日已完成打卡或已跳过后重复刷卡 | 提示当日已完成记录，不重复更新状态 |
| 设备未开启NFC功能 | 提示用户开启系统NFC功能 |
| 今日不打卡确认过程中取消或中断 | 任一阶段点击取消即退出确认流程，跳过不生效 |

## 6. 验收标准

1. 用户在设置页面可成功录入NFC卡信息，并配置提示时间与间隔时间。
2. 工作日到达设定时间后，App能准时发出消息通知与震动。
3. 在提醒状态下点击延迟5分钟，App在5分钟内不提醒，5分钟后恢复提醒。
4. 在未扫描NFC卡或未跳过打卡前，App按设定的间隔时间重复触发提醒。
5. 使用已录入的NFC卡贴近手机扫描后，能成功识别并终止提醒，日历页面对应日期显示已打卡标记，累计打卡天数增加。
6. 在设置页面点击「今日不打卡」，在连续完成3次确认后成功跳过今日打卡并停止提醒，日历对应日期以区别于已打卡的独立样式进行展示，累计打卡天数不增加。
7. 所有打卡记录、跳过记录及配置数据完全保存在本地，无网络环境下功能完整可用。

## 7. 本期不实现功能

2. 多张NFC卡同时绑定与管理
3. 打卡数据导入与导出备份
4. 自定义铃声与铃声音量调节
